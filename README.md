# tuhui2020.github.io

涂汇（TU Hui）的个人学术主页，使用原生 HTML、CSS 和 JavaScript 构建并部署于 GitHub Pages。

## 页面

- `index.html`：中文个人主页
- `index-en.html`：英文个人主页
- `projects.html` / `projects-en.html`：中英文 GitHub 项目列表
- `readme.html` / `readme-en.html`：中英文项目 README 阅读页
- `nav.html`：共享导航和中英文切换入口

## 主要文件

- `styles.css`：全站样式与响应式布局
- `script.js`：导航加载、语言适配、项目读取和 README 展示
- `images/`：个人照片与站点图像

中英文页面可通过右上角的语言控件切换，并保留当前页面与项目参数。
